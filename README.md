# Fraud Detection Project

This project applies machine learning techniques to detect fraudulent financial transactions.

## Files
- fraud_detection_model.ipynb: Final modelling notebook (feature engineering, Random Forest, XGBoost)
- EDA.ipynb: Exploratory data analysis

## Models Used
- Random Forest (baseline)
- XGBoost (final model)

## Key Features
- balance_error
- is_full_drain
- is_logical

## Results
Both models achieved high performance due to strong separation between fraudulent and non-fraudulent transactions.
